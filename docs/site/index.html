Claude Aqui

Clique com o botão direito em uma pasta e abra o Claude Code nela, já em um terminal.

Baixar Código no GitHub

Gerenciadores de arquivos

  • Nautilus (GNOME Files)
  • Dolphin (KDE)
  • Nemo
  • Caja
  • Thunar
  • PCManFM-Qt

Instalar

Baixe o pacote da última versão na página de releases:

# Debian, Ubuntu, Mint
sudo apt install ./claude-aqui_*_all.deb

# Fedora, openSUSE
sudo dnf install ./claude-aqui-*.noarch.rpm

# Arch, Manjaro
sudo pacman -U claude-aqui-*.pkg.tar.zst

Abra Claude Aqui no menu de aplicativos e ative os gerenciadores que você usa. Sem root: o item de menu é instalado só para o seu usuário.

Como funciona

  • Detecta o terminal instalado (gnome-terminal, Ptyxis, Konsole, Kitty e outros) ou deixa você escolher.
  • O caminho da pasta nunca passa por string de shell: nomes com espaços, aspas ou $ são seguros.
  • Ao sair do claude o terminal fecha; em caso de erro mostra a mensagem e espera uma tecla.
  • O Claude Code precisa estar instalado (claude.com/claude-code).
